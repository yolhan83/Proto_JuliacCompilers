Julia 1.12 marked a turning point for compilation and deployment: introducing experimental
dead-code trimming (`--trim`), the `JuliaC.jl` CLI driver, native `Pkg` Apps (`pkg> app add`),
and a Pkg-switchable `Compiler` standard library.

<!--more-->

Four foundational capabilities landed together in the Julia 1.12 cycle and shaped the entire
2025–2026 tooling wave:

- **Code trimming (`--trim=safe`)**: Uses static reachability analysis from `@main` and
  `@ccallable` entry points to prune unused IR, metadata, and stdlibs—shrinking minimal
  executables from ~150 MB down to ~1–2 MB (plus a compact runtime bundle).
- **[`JuliaC.jl`](/compilers/juliac/)**: Provides a clean `juliac` CLI and programmatic
  `ImageRecipe` / `LinkRecipe` / `BundleRecipe` pipeline for executables, shared libraries,
  sysimages, object files, and LLVM bitcode.
- **Native `Pkg` Apps**: Allows CLI tools declaring `function (@main)(args)` to be installed
  globally via `pkg> app add PackageName` into `~/.julia/bin`.
- **Upgradable `Compiler` stdlib ([`BaseCompiler.jl`](https://github.com/JuliaLang/BaseCompiler.jl))**:
  Decouples Julia's compiler from the runtime binary so compiler branches and tooling (like
  `JETLS.jl` and `JuliaLowering.jl`) can evolve rapidly per environment.

Learn how to use these features today in [Get started](/get-started/) and the
[`JuliaC.jl` guide](/compilers/juliac/).
